# Cross-industry analogy bank

Patterns that solved a problem in one field and can transfer to another. Use them as springboards, not answers.

| Pattern | Origin example | Transferable idea |
| :--- | :--- | :--- |
| Share idle assets | Airbnb (Travel), Uber (Transport) | Turn underused things people own into supply |
| Remove friction at the point of action | Contactless NFC payment (Fintech, Retail) | Collapse a multi-step task into one tap |
| Pay per use instead of owning | Rolls-Royce "Power by the Hour" (Manufacturing, Defence) | Sell outcomes or uptime, not products |
| Triage by urgency | Emergency-room triage (Healthcare) | Sort requests by severity before handling them |
| Checklists to prevent errors | Aviation pre-flight checklists (Transport) | Standardize the few critical steps |
| Subscription and personalization | Netflix, Stitch Fix (Entertainment, Fashion) | Learn preferences and ship curated bundles |
| Gamified progress | Duolingo streaks (Education) | Small daily wins with visible streaks |
| Mobile money without banks | M-Pesa (Telecommunications, Kenya) | Use an existing network as the rails for a new service |
| Frugal innovation | Jaipur Foot, Aravind Eye Care (Healthcare, India) | Assembly-line process for radically lower cost |
| Peer-to-peer trust | eBay ratings (E-commerce) | Reputation systems instead of gatekeepers |
| Demand-based pricing | Airline yield management (Travel), smart-grid pricing (Utilities) | Price by time and demand to smooth peaks |
| Just-in-time | Toyota Production System (Manufacturing) | Make or deliver only what is needed, when needed |
| Self-service with a safety net | Self-checkout (Retail), IKEA flat-pack | Let users do part of the work, with help on hand |
| Mass customization | Nike By You (Fashion) | Standard base with user-chosen variations |
| Open platforms | App stores (IT) | Let third parties build on your core |
| Swarm and decentralize | Ant colonies, mesh networks (Nature, Telecommunications) | Many simple agents instead of one central controller |
| Self-cleaning surfaces | Lotus leaf (Nature, biomimicry) | Design the problem out instead of cleaning up after |
| Community collective | Rotating savings clubs like tontines and susu (West African and other cultures) | Pooled group contributions with rotating payouts |
| Ritual and hospitality | Japanese omotenashi (Hospitality) | Anticipate needs before they're voiced |
| Wearable monitoring | Fitness trackers (Healthcare, IT) | Continuous passive data to trigger early action |
| Simulation training | Flight simulators (Defence, Transport) | Practice rare, high-stakes moments safely |
| Last-mile lockers | Amazon Lockers (E-commerce), Japanese konbini pickup | Shared pickup points instead of home delivery |
